# Play Store release checklist

- [ ] Integrate and test the SQLite database on physical Android devices.
- [ ] Test role assignment, duplicate names, 3–20 players, 1–(players-1) imposters, hint on/off, voting timer, app background/restore, and custom word import/export.
- [ ] Decide the exact data collected. Keep the privacy policy accurate.
- [ ] Create a signed release Android App Bundle (AAB); do not upload a debug APK as the production release.
- [ ] Create app icon, feature graphic, phone screenshots, store description, and support contact.
- [ ] Complete the Play Console Data safety form, content rating questionnaire, target audience declarations, and app access details truthfully.
- [ ] Review Google Play's current sexual-content and user-generated-content policies. Explicit pornography or sexually gratifying content can cause rejection; an “18+” label does not override store policy. Use a store-safe word pack for the Play Store release and keep any user-customizable content compliant.
- [ ] Verify current target API level and other technical requirements in Play Console before submission.
